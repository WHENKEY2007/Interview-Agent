## Getting Started

1. Run `npm install`
2. Run `npm run dev`

## Testing

Run:
```bash
npm test
```
The test suite covers:
* **Planner**: Reinforcement planning, target difficulty adaptation.
* **Conciseness & Validation**: Sentence lengths, preambles, and duplicate semantic overlap checks.
* **Adaptive Engine**: Decisions, pacing guards, and fallback question recovery.
* **Feedback Engine**: Qualitative strengths, gaps, and cohort next steps.
* **Hackathon Readiness**: API contracts, Emily/Ethan adaptation rules.
* **Fabricated Feedback**: Zero-answer null scores, whitespace exclusions, and session resets.
